Installation de l'admin

À faire une seule fois : créez le compte administrateur.

Elle permet à l'admin d'enregistrer sur votre dépôt. Elle sera chiffrée avec votre mot de passe : vous n'aurez plus à la saisir.

Comment obtenir la clé GitHub ?
  1. Sur GitHub : photo de profil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Resource owner : l'organisation propriétaire du dépôt.
  3. Repository access : « Only select repositories » → le dépôt de l'affichage.
  4. Permissions → Repository permissions → Contents : « Read and write ».
  5. Expiration : 1 an → Generate token → copiez la clé ici.
